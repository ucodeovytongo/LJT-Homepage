# Junteng Liu - Personal Homepage

This is the personal academic homepage of **Junteng Liu**, a first-year PhD candidate at [HKUST NLP Group](https://hkust-nlp.github.io/), Hong Kong University of Science and Technology.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll theme.

## Structure

- `_pages/about.md` - About me (landing page)
- `_pages/publications.html` - Publications listing
- `_publications/` - Individual publication entries
- `_config.yml` - Site configuration
